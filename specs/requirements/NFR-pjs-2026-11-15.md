# Non-Functional Requirements: PJS

> [!abstract]
> Quality attributes of PJS organised by ISO/IEC 25010. Targets are the values enforced in code today (with the owning spec) or explicitly marked as unmeasured. Nothing here is a new commitment; verification state is as of 2026-11-15.

> [!info] Quality priority order
> Security > Correctness (reliability) > Performance > Maintainability > Portability > Usability. Trade-off rule: a security limit is never relaxed for throughput; performance regressions above 10 percent are P1 ([[constitution]]).

| ID | Requirement | Target | Verification | State |
|----|-------------|--------|--------------|-------|

| NFR-PERF-002 | SIMD JSON parsing via `sonic-rs` | runtime CPU dispatch; no SIMD vs scalar bench | [[041-simd-features-and-global-allocator/spec\|041]] | unmeasured |
